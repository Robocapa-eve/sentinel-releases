# THREE SYSTEMS DEFINE SENTINEL

## 💀 LIVE KILL MAP

### **Live kill activity across New Eden — analyzed, mapped and configurable.**

SENTINEL consumes live kill activity and resolves it against the New Eden universe graph so events can become part of the tactical map instead of remaining isolated feed entries.

The pilot can gain immediate context such as:

- event system,
- jump distance from the active monitoring origin,
- event freshness,
- ship / kill context,
- map position,
- and surrounding route context.

Tactical presentation is configurable through systems such as Kill range, marker persistence, pulse / radar lifetime, threat colors and alert behavior.

The result can be used both ways: **see danger developing around your operation, or scan New Eden for active areas and potential content.**

A kill several jumps away becomes more useful when you know **where it happened, how close it is and whether the route matters to you.**

---

## 🚨 UNIQUE TACTICAL LIVE MAP WARNING SYSTEM

### **Your Overview tells you what's on grid. SENTINEL helps you understand what's happening beyond it.**

SENTINEL's **Unique Tactical Live Map Warning System** is designed to transform relevant live activity into an active warning layer around the position you are actually monitoring.

It combines:

- live map indicators,
- tactical pulses,
- configurable jump ranges,
- event persistence,
- monitoring-origin awareness,
- route and system context,
- native Windows audio,
- separate Kill / Intel alert profiles,
- and threat-oriented visual presentation.

Used defensively, this provides earlier awareness of activity that may matter to your operation. Used offensively, the same live picture helps show where activity is building and where the next fight or roaming destination may be.

The goal is simple: reduce the time between **something happening in New Eden** and **the pilot understanding whether it matters**.

> **From raw kill events to tactical awareness.**

---

## 🛰️ MULTI-CHANNEL INTEL MAP

### **Multiple Intel channels. One map. One tactical picture.**

EVE Intel rarely arrives through one perfect source.

SENTINEL can discover local EVE chat-log channels and allows pilots to explicitly enable multiple Intel channels for monitoring. Relevant reports are parsed, resolved and associated with New Eden systems before being placed into the same tactical context used by Kill, Scout, Watchlist and Threat systems.

That means the pilot does not have to mentally combine several chat windows with a separate map and route planner.

### **One map. Multiple intelligence sources. One tactical picture.**
