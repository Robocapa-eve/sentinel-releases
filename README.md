# SENTINEL // TACTICAL INTELLIGENCE

> **Real-time tactical situational awareness for EVE Online**  
> Live intelligence · threat context · New Eden mapping · Windows x64

SENTINEL is an independent tactical companion application for EVE Online, built around one idea: **give pilots a clearer picture of what is happening around them without turning the interface into noise.**

This repository is the **public release and development-history channel** for SENTINEL. The application source code remains private, while builds, release information and meaningful development milestones are documented here for the EVE community.

## WHAT SENTINEL IS BECOMING

SENTINEL is being developed as a dedicated tactical workspace for areas such as:

- 🛰️ live intelligence monitoring,
- 🗺️ New Eden system and route awareness,
- ⚠️ threat and kill context,
- 🔔 native tactical alerts,
- 👁️ scout / monitoring-origin workflows,
- 🪟 a persistent Windows desktop and tray experience.

The aim is not to automate gameplay. The aim is to make **available information easier to understand and act on**.
