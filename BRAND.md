# SENTINEL Brand System

SENTINEL uses a single locked brand mark: the hexagonal neural/brain network with one central node and four directional nodes.

## Canonical geometry

The geometry is part of the identity. Do not redraw, stretch, rotate, rearrange the nodes, change the relative proportions, add a different outline or substitute another brain/network silhouette.

## Mark variants

- **Hero** — full luminous treatment for large presentation surfaces and campaign artwork.
- **Sharp** — clean/no-glow operational mark for GitHub, the Windows app, tray, taskbar, installer and small placement.
- **Flat** — reduced two-colour treatment for documentation, favicon-style use and constrained reproduction.
- **Mono White / Mono Black** — one-colour fallbacks for watermark, print and special-use contexts.

The public repository currently uses the **Sharp** mark as its default GitHub identity so the logo remains crisp at small sizes.

## Language

Primary product descriptor: **Tactical Intelligence for EVE Online**

Secondary brand line: **OBSERVE · ANALYZE · PROTECT**

Campaign copy such as **KEEP YOUR TOOLS. ADD INTELLIGENCE.** may continue to be used independently.
